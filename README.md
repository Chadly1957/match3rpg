# Match 3

A simple match-3 puzzle game built with React, TypeScript, and Vite.

## Current features

- 3x3 grid with three icon types: Star, Square, Circle
- Drag and drop to swap two adjacent icons (mouse and touch supported)
- Swapping checks both cells for a 3-in-a-row match; matches are kept and highlighted, non-matches are swapped back

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Deploys to Vercel as a static Vite build.
